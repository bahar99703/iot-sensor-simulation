# iot-sensor-simulation
A simple software project aimed at exploring sensor-data acquisition and processing concepts without physical hardware 


##Features
-Simulated temperature readings between 18C to 30C

-Simulated humidity readings between 30% and 70%

-UNIX timestamp after each reading

-Formats sensor readings to JSON

-Generates 20 readings with 1 second interval between each measurement
